# ALLGORИТМ — демо-сайт студии танцев и акробатики (Северодвинск)

Одностраничный сайт-визитка: чистые HTML, CSS и немного JavaScript. Без фреймворков, сборщиков и внешних скриптов, только шрифты Google Fonts (с системными запасными).

```
index.html        вся разметка и тексты
css/style.css     стили (палитра — токены в начале файла)
js/main.js        меню, анимации, подборщик по возрасту, демо-форма
img/              favicon.svg, og.png (картинка для соцсетей), сюда же — фото студии
docs/VERIFY.md    что подтвердить у студии и что у неё запросить
docs/DECISIONS.md решения по дизайну и контенту
```

## Открыть локально

```bash
cd allgoritm
python3 -m http.server 8000
```

Затем открыть http://localhost:8000. Можно открыть и сам `index.html` двойным кликом, но через сервер поведение ближе к настоящему.

## Опубликовать на GitHub Pages

Репозиторий `Candellak1/allgoritm-demo` сейчас **приватный**. На бесплатном тарифе GitHub Pages работает только для публичных репозиториев, поэтому:

1. Сделать репозиторий публичным (GitHub → Settings → General → Danger Zone → Change visibility) или командой:
   ```bash
   gh repo edit Candellak1/allgoritm-demo --visibility public --accept-visibility-change-consequences
   ```
2. Включить Pages: Settings → Pages → Source: «Deploy from a branch», ветка `main`, папка `/ (root)`. Или командой:
   ```bash
   gh api -X POST repos/Candellak1/allgoritm-demo/pages -f "source[branch]=main" -f "source[path]=/"
   ```
3. Через 1–2 минуты сайт откроется по адресу https://candellak1.github.io/allgoritm-demo/

Все пути относительные (`./css/…`, `./js/…`), поэтому сайт работает и из подпапки. Если адрес будет другим (свой домен), замените его в `index.html` в `canonical`, `og:url`, `og:image` и JSON-LD.

Дальнейшие правки: `git add -A && git commit -m "…" && git push`, Pages обновится сам.

## Заменить фото студии

Фото на сайте нет намеренно: на снимках в группе дети, нужно разрешение студии. Когда студия пришлёт фото и подтвердит, что их можно использовать:

1. Положите 6 файлов в `img/` с именами `photo-1.jpg` … `photo-6.jpg` (вертикальные 4:5, примерно 800×1000, до 150 КБ каждый).
2. В `index.html` найдите секцию `id="gallery"`, уберите у неё атрибут `hidden` и впишите каждому `<img>` осмысленный `alt` (например, «Команда на соревнованиях в Северодвинске, май 2026»).

Пока у секции стоит `hidden`, пустых плиток на странице нет и картинки не загружаются.

## Убрать демо-пометки

В первой строке `index.html` удалите атрибут `data-demo-mode` у тега `<html>`:

```html
<html lang="ru" class="no-js" data-demo-mode>   →   <html lang="ru" class="no-js">
```

Это скроет все элементы с `data-demo`: подпись разработчика в футере и пометки «Демо» у формы.

Для рабочей версии форму нужно подключить к отправке (например, бот в Telegram или сообщения сообществу ВКонтакте). Сейчас она только проверяет поля и показывает экран успеха.

## Что где менять

- **Тексты** — прямо в `index.html`, каждая секция подписана комментарием.
- **Цвета** — токены `--violet-*`, `--magenta*`, `--lime`, `--paper`, `--ink` в начале `css/style.css`.
- **События** в ленте «Выступления и поездки» — элементы `<li class="ticket …">`; цвет плашки задаёт класс `ticket--violet` / `ticket--magenta` / `ticket--lime`.
- **Возрасты направлений** для подборщика — атрибуты `data-min` / `data-max` у карточек `.dir` (пустой `data-max` значит «без верхней границы»).
