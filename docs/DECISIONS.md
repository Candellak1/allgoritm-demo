# Решения по дизайну и контенту

## Концепция: «Алгоритм движения»
Название студии — это алгоритм + ритм. Всё на странице строится на двух образах:
- **ритм**: эквалайзер (эхо логотипа студии), волны-линии (эхо обложки ВКонтакте), бегущая строка;
- **алгоритм**: последовательность шагов. Пирамида в hero собирается по ярусам с подписями «1 основание → 2 второй ярус → 3 вершина», путь «Как начать» прочерчивается по шагам.

Главный «вау» сосредоточен в одном месте — в hero (пирамида + эквалайзер). Остальные секции спокойнее, чтобы не превращаться в набор эффектов.

## Палитра
| Токен | Hex | Роль |
|---|---|---|
| `--violet-900` | `#1b0f3a` | тёмный фон |
| `--violet-700` | `#3f2380` | основной фиолетовый |
| `--violet-500` | `#6c46d8` | градиенты, нижний ярус пирамиды |
| `--magenta` | `#e2399b` | декоративный акцент (фигуры, свечение) |
| `--magenta-ink` | `#d42a8c` | фон кнопок с белым текстом (контраст 4.66:1) и текст на светлом |
| `--lime` | `#e6f24b` | яркий акцент на тёмном, верх пирамиды |
| `--paper` | `#fbf9ff` | светлые секции |
| `--ink` | `#20143f` | текст на светлом |

Фирменная магента `#e2399b` даёт с белым текстом только 3.97:1, поэтому для кнопок взят чуть более глубокий `#d42a8c`. Визуально это тот же цвет.

## Шрифты
- **Unbounded** (500/700/900): заголовки и логотип. Широкий геометричный гротеск с кириллицей, похож на столбики эквалайзера.
- **Onest** (400–700): основной текст.
- Шрифты грузятся неблокирующе (`preload` + `onload`), фолбэки: `Arial Black`/`system-ui` и системный sans. Если Google Fonts недоступен (бывает в РФ), сайт остаётся читаемым.

## Проверка плана на «шаблонность» и что изменено
1. **Демо-лента сверху убрана.** На телефоне она съедает ~30 px первого экрана. Демо-пометки остались в футере и под формой (`data-demo`).
2. **Заголовок hero одного цвета**, без выделения одного слова цветом. Характер даёт сам шрифт и масштаб.
3. **События — «билеты»** с перфорацией, а не одинаковые карточки: это поездки и выступления, образ билета точнее.
4. **«Почему выбирают нас»** — не четыре одинаковые карточки с тенью, а список с крупными пиктограммами и разделителями, рядом блок с реальными цифрами.
5. **Номера** стоят только там, где есть последовательность: ярусы пирамиды, шаги «Как начать», а также номера направлений (по требованию ТЗ).

## Контент
- **«Первая неделя занятий — бесплатно!»** выводится дословно, как у студии; актуальность акции — в `VERIFY.md`.
- **«Один тренер на все группы»** выводится формулировкой из закреплённого поста; подтверждение — в `VERIFY.md`.
- **Подборщик по возрасту.** Диапазоны пересекаются (танец 3–17, пирамида 4–17, чир от 4), поэтому для 6–17 лет подходят все три направления. Для 3–5 лет отдельно сказано, что в 3 года доступен только акробатический танец. Логика читает диапазоны из атрибутов карточек, поэтому ветка «напишите нам, подскажем» в коде есть и сработает, если диапазоны поменяются.
- **События** поданы как архив прошедших выступлений (сейчас ноябрь 2026). Где в названии альбома нет типа события, указан только город.
- **В форму добавлено необязательное поле «Направление»**: кнопки «Хочу попробовать» заполняют его сами. Это удобно и не требует новых фактов.
- **Карта не встраивается** (это сторонний скрипт и лишний вес), вместо неё кнопка «Маршрут» в Яндекс.Картах.
- **Курсор-«ритм»** не делался: ТЗ разрешает его пропустить, а для такого сайта это лишний эффект.
